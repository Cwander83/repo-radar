# repo-radar

A macOS desktop widget that gives a glance at your GitHub repos:

- Open pull requests
- Failing CI
- Stale branches

Native Swift (host app + WidgetKit extension), free to run, GitHub only.

## Requirements

- macOS 14+ (desktop widgets)
- Full Xcode (not just Command Line Tools)
- `gh` CLI, authenticated
